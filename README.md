# Calculator

## A simple calculator with HTML, Tailwind CSS, JavaScript.

# Features

## Addition, Subtraction, Multiplication, Division.

## Decimal numbers.

## Clear buttons (C).

## Basic error handling (invalid expressions, division by zero).

# Demo

## Live demo (after enabling GitHub Pages): https://zahraahmadi05.github.io/my-calculator/

# Getting Started

## 1. Clone the repository:

### git clone https://github.com/zahraahmadi05/my-calculator.git

## 2. Open the project folder and double-click index.html to run it in your browser.

### No installation or build step is needed.

# Built With

## HTML5

## Tailwind CSS

## JavaScript

# How It Works

## Each button appends its value to the display. Pressing = validates the expression with a regular expression (only digits and + - \* / . ( ) are allowed) and then evaluates it. Invalid input or division by zero shows Error.
